# Changelog

All notable changes to NIXFact will be documented in this file.

## [0.1.0] - 2026-03-05

### Added
- **Offertes**: Create and manage quotations with auto-numbering (OFF-YYYY-MM-NNN)
- **Facturen**: Sales invoices with BTW calculation, due dates, and PDF generation
- **Inkoopfacturen**: Purchase invoice tracking with expense categories and project linking
- **Abonnementen**: Recurring billing (monthly, quarterly, semi-annual, annual)
- **Mollie integration**: Online payment links via iDEAL, creditcard, and more
- **Bank integration**: Ponto API transaction import with 3-tier automatic matching
- **UBL 2.1 e-invoicing**: Peppol BIS 3.0 compliant XML generation
- **Herinneringen**: Automated payment reminders and collection notices
- **Statistieken**: Revenue dashboards, VAT reports, cost analysis
- **Email templates**: Professional Dutch-language invoice and reminder emails
- **Multi-company**: Support for multiple companies with per-company settings
- **Auto-numbering**: Configurable prefix/year/month/sequence per document type
- **i18n**: Full translations in NL, EN, FR, DE, ES
- **Docker deployment**: Complete Docker Compose setup with MariaDB, Redis, workers
- **Operational scripts**: Backup, restore, and update automation
