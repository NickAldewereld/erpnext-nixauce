Gebouwd op ERPNext

NIXFact is een Frappe-app die naadloos integreert met het ERPNext-ecosysteem. Gebruik bestaande klant-, leverancier- en bedrijfsgegevens, of draai standalone.

Frappe Framework v17+
ERPNext v17+
Mollie Payments API
Ponto Banking API

Installatie

# Voeg NIXFact toe aan je bench
bench get-app https://github.com/NickAldewereld/erpnext-nixauce

# Installeer op je site
bench --site jouw-site.local install-app nixfact_integration

# Of gebruik Docker
cd deployment/docker
cp .env.example .env
# Pas .env aan met je instellingen
docker compose up -d
